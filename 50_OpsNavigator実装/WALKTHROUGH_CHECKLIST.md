# WALKTHROUGH_CHECKLIST.md — Gate 1 ウォークスルー(吉川さん用・30〜45分)

- 対象: 情シス Ops Navigator Clickable Prototype(合成デモデータのみ)
- 起動: `pnpm install && pnpm build && PORT=3111 pnpm start` → http://127.0.0.1:3111
- 記録者が各項目に ✅/❌ と気づきを記入してください。❌は差戻し理由になります
- これは操作確認です。「説明を聞いた」だけでは受領になりません

## A. ホーム(5分)

- [ ] 開いてすぐ「今日やるべきこと」(A0・期限・承認待ち)だけが見える
- [ ] 全43業務の巨大な表が出ていない
- [ ] R3(PC紛失)の警告が色以外(文字)でも分かる
- [ ] 「次の30日」から業務詳細へ移動できる

## B. 発生時アクション(10分)

- [ ] 15枚のカードがすべて表示される
- [ ] 「Wi-Fi・全社ネットワーク障害」を開くと、まずすること/やってはいけないことが最初に見える
- [ ] 初動ガイドに「一般的推奨・社内適用は要確認」のラベルが付いている
- [ ] 関連業務に「提案(PROPOSED)」バッジが付いている(確定表示になっていない)
- [ ] ホーム→カード→業務詳細まで3クリック以内で到達できる
- [ ] 「退職」カードがR2(承認必須)として表示される

## C. 業務43(5分)

- [ ] 初任者モードでは行が絞られており、解除すると43件になる
- [ ] どの行も優先度が「要確認」表示になっている(勝手にA0等が入っていない)
- [ ] 業務詳細で、未整備の項目が「要確認」と正直に表示される

## D. ケース(10分)

- [ ] 新規ケース作成で必須7項目だけを聞かれる
- [ ] 概要に「password: xxx」と書くと保存がブロックされる
- [ ] PC紛失ケース(R3)に「承認・証跡なしで完了不可」の警告が出る
- [ ] Drive外部共有ケースで「要突合(正本競合)」が表示され、方針A/Bが並記される

## E. AI相談(5分)

- [ ] 「全社のWi-Fiがつながらない」で、社内根拠(Runbook出典)付きの回答が出る
- [ ] 「見たことがないSaaSのエラー」で、社内未確認と一般論が分けて表示される
- [ ] どちらの回答も9項目の順序(緊急度→まずやること→…→出典)で表示される
- [ ] パスワード等の入力を求められない

## F. 緊急パック・モバイル(5分)

- [ ] 緊急パックに代表4事象の初動が表示される
- [ ] 機内モード(またはDevToolsのOffline)にしてリロードしても緊急パックが開ける
- [ ] オフライン中は「オフラインです・情報が古い可能性」の表示が出る
- [ ] スマホ幅(またはブラウザを縮めた状態)で下部タブから主要画面を操作できる
